# 小白竞品拆解助手

把淘宝/天猫竞品链接或页面截图，变成“可学习、可反打、可避开、可测试”清单的电商竞品拆解 AI Skill。

- 当前版本：`v0.1-public`
- 方法论设计：电商老兵小白（jiaowoxiao_bai）
- 官方仓库：https://github.com/jxyfffb/xiaobai-competitor-analyzer

这是免费公开版。使用和传播边界以 [TERMS.txt](TERMS.txt) 为准。

## 适合什么时候使用

- “我想看看这个竞品为什么可能卖得好。”
- “我不知道竞品强在哪里，自己的商品该补什么。”
- “我想做竞品对标，但不知道从哪里拆起。”
- “我担心 AI 编造竞品后台数据，希望结论能区分事实和推断。”

本工具适合淘宝、天猫商品级竞品分析。只提供一条链接、一张主图或少量截图，也可以先做快速拆解。

## 它会怎样工作

1. 接收竞品链接、页面截图、评价或问大家内容。
2. 根据资料量自动选择快速、标准或深度拆解，不让用户反复选择。
3. 先判断它是直接竞品、单点学习样本，还是不建议对标。
4. 还原“怎么被看到 → 为什么被点击 → 为什么被相信 → 为什么可能下单”的成交链路。
5. 给关键结论标注证据等级，最后输出可学习、可反打、可避开、可测试清单。

证据等级：

- 🟢 事实可见：资料中明确出现。
- 🟡 合理推断：由多个可见信息交叉推断。
- 🔴 待验证：证据不足，需要补资料或小范围测试。

## 新手怎么下载安装

### 1. 下载完整文件夹

打开本仓库，点击右上方绿色 **Code** 按钮，再点击 **Download ZIP**。GitHub 下载后通常得到 `xiaobai-competitor-analyzer-main` 文件夹；可以将它改名为 `xiaobai-competitor-analyzer`。请保留整个文件夹，不要只取 `SKILL.md`。

### 2. 安装 Skill

方式 A：如果你的 AI 助手提供“导入 Skill”“安装 Skill”或类似入口，选择解压后的完整文件夹。

方式 B：如果平台支持本地 `skills` 目录，把完整文件夹复制进去，然后重启或刷新 AI 助手。

不同 AI 平台对 Skill 的支持方式不同；如果平台不支持导入，可以把 `SKILL.md` 和本次竞品资料一起交给 AI 阅读并执行。

### 3. 第一次调用

安装完成后可以直接说：

```text
请用小白竞品拆解助手分析这个淘宝/天猫竞品。
我先提供链接和页面截图，请按资料量自动选择模式，并输出可学习、可反打、可避开、可测试清单。
```

建议第一次先提供主图、详情页首屏和 5—10 条评价截图。链接打不开或要求登录时，不要绕过平台限制，改传截图或文字即可继续。

## 数据与使用边界

- 分析只基于用户提供的链接、截图、文字、表格和公开可见信息。
- 无法看到的真实成交额、转化率、投放数据、利润和搜索流量不会被编造。
- 页面内容需要登录或遇到验证码时，不绕过登录、风控、验证码或反爬限制。
- 上传后台截图前，请遮盖账号、订单、手机号、客户信息和其他敏感数据。
- 食品、母婴、医疗、保健和功效类商品，需要结合最新广告法、平台规则和专业意见复核。
- 输出只用于运营分析、策略讨论和创意参考，不承诺销量、点击率、转化率、排名或收益。
